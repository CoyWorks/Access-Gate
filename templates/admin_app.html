Install admin app

Home Screen app

Android: open this portal in Chrome and use Install app / Add to Home screen in the browser menu. iPhone/iPad: open in Safari, use Share → Add to Home Screen, then open the new icon. Web Push requires iOS/iPadOS 16.4 or later.

Access-request notifications

Open this page inside the installed app, then enable notifications. Alerts use generic text and open the pending Requests screen, where you can Approve or Deny. The phone needs Internet for push delivery and VPN/local access to open administration.

Checking notification support…

Notifications stop when this admin login expires (seven idle days), you sign out, or admin security settings change. After signing in again, press Enable notifications again. Delivery does not renew your login. Enable notifications separately on each phone/app installation.

A denied browser permission must be reset in your phone/browser settings. A certificate warning cannot be bypassed for service-worker installation: the portal CA must be fully trusted. No administration data is cached for offline access.
