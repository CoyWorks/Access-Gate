Review the script from a trusted download, compare this file hash independently, and inspect it before running:

Get-FileHash .\access-gate-client.ps1 -Algorithm SHA256
.\access-gate-client.ps1 -Action Inspect
.\access-gate-client.ps1 -Action Install -ConfirmTrust

.\access-gate-client.ps1 -Action Remove -ConfirmTrust

{% endif %} {% if platform=='ios' %}
  1. Download the device CA in Safari. Open Settings → Profile Downloaded, or General → VPN & Device Management, and install the downloaded certificate/profile.
  2. Then open Settings → General → About → Certificate Trust Settings. Enable full trust for the root whose fingerprint you verified.
  3. Return to this page in Safari and reopen the portal. A certificate being installed alone does not confirm full TLS trust.
{% elif platform=='android' %}
  1. Download the device CA. Open Settings and search for “Install a certificate” or “CA certificate”. Commonly this is under Security → Encryption & credentials.
  2. Choose CA certificate, confirm with your device unlock method and select the downloaded file. Menu names depend on the manufacturer.
  3. Open the portal in your browser. Some apps do not trust user-installed CAs; installing this certificate does not make every app compatible.
{% elif platform=='windows' %}
  1. Open the downloaded certificate and compare its fingerprint with your administrator's value.
  2. Choose Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities. Confirm only the CA you verified.
  3. Restart the browser and open the portal. Browsers with a separate certificate store may require separate configuration.
